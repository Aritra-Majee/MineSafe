# MineSafe

MineSafe is a safety-first web app for mining crews to complete pre-shift equipment checks, report defects, and access emergency guidance.

## Features

- Worker sign-in with a role-based checklist
- Pre-shift verification for PPE, safety devices, and medical supplies
- Defect reporting that blocks the shift and alerts supervisors
- Supervisor dashboard for active safety alerts
- Emergency protocols and equipment reference guide

## Tech Stack

- React
- Vite
- Tailwind CSS
- lucide-react

## Getting Started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the development server

   ```bash
   npm run dev
   ```

3. Open the local Vite URL shown in the terminal.

## Build
